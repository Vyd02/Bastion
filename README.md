# Bastion Launcher

A privacy-first Android home screen.

- **Hidden Private Space** — Android 15+ Private Space, reachable only from ⋮ › Privacy Center
- **Locked apps** — fingerprint/PIN before opening
- **Vault** + **Stealth mode** — apps vanish everywhere; open with a secret code typed in search
- **Auto-lock** on screen off, screenshot blocking, animated UI
- **Auto-updates** — the app reads `update.json` in this repo

Install [Bastion.apk](https://github.com/Vyd02/bastion/raw/main/releases/Bastion.apk), then set Bastion as your default home app.
